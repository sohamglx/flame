---

## String Formatting

You can format strings using arguments via `fmt.format`.

```flame
import std.fmt



let a = (spidey, peter)
let (name, rname) = a

let formated = fmt.format("hello {} - {}", name, rname)

println(formated)

```

## API Summary Table

| Method | Arguments | Returns | Description |
| :--- | :--- | :--- | :--- |
| `fmt.format` | `template: String, args: Unknown` | `String` | Formats a template string using either a vector of positional arguments or a formula of named arguments. |
